检测贴标，从头到尾。

一款离线优先的技师手机应用、一个办公室后台，以及支撑两者的同一套 API——由 Yonder Tech 设计并开发。

类型
产品 · 自主设计与开发

iOS · Android · 网页

Expo / React Native · React · Fastify · Prisma
规模
3 个应用 · 54 个 API 接口
01

课题

电器检测贴标是合规工作：现场每一件电器都要检测、贴标、记录，客户需要一份经得起检查的报告。现实中它靠的是纸板夹、客户手工维护的表格，以及技师对上一次的记忆。

需求是一套从机房一直贯通到报告的系统：技师在没信号的地方单手就能用的应用，办公室能用来运营整个业务的后台，以及在两边含义完全一致的记录。

02

设计决策

01

一个共享包承载全部领域逻辑——编号区间展开、连续记录合并、区域分组、复检周期计算、Excel 解析器和设计令牌——让手机、后台和服务器对“一条记录是什么”不可能有分歧。

02

手机端离线优先。检测记录和故障照片先排队存在设备上，有信号再同步；同一批记录同步两次也不会出错，而且没有原因和照片，故障就无法保存。

03

绝不盲目导入。客户的登记表先解析、先展示——从空白单元格推断区域，从自由文本备注里读出结论——确认后才写入资产登记、上次检测记录和下一次任务。

03

结果

已上线：一款支持 iOS、Android 和网页的 Expo 应用，一个可安装的 React 后台，以及一套能出具并归档 PDF 报告的 Fastify + Prisma API。生产环境用 Postgres，开发环境在 SQLite 上跑同一套表结构；190 项测试全部通过，其中一项通过 HTTP 跑完整个业务流程。
